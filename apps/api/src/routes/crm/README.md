# CRM Routes Module

Admin dashboard for managing CRM contacts, email campaigns, and lead funnel analytics.

## Quick Start

```typescript
import { createCrmRoutes } from './index.js';

// Mount CRM routes in Express app
app.use('/crm', createCrmRoutes(container));
```

## Structure

```
crm/
├── index.ts          - Barrel export and main entry point
├── contacts.ts       - Contact management endpoints
├── campaigns.ts      - Email campaign management
├── leads.ts          - Lead funnel tracking
├── templates.ts      - HTML rendering utilities
└── middleware.ts     - Authentication middleware
```

## Routes Overview

### Contacts Domain
Manage CRM contacts with funnel segmentation.

```
GET    /              List contacts with filtering
GET    /user/:userId  View contact details
POST   /api/cancel-email/:id
POST   /api/cancel-all-emails/:userId
POST   /api/update-stage/:userId
```

### Campaigns Domain
Manage email campaigns and templates.

```
GET    /emails                Email queue dashboard
GET    /templates             Template browser
POST   /api/process-emails    Process pending emails
POST   /api/invite/:userId    Send invite email
```

### Leads Domain
Track lead conversions and email interactions.

```
GET    /funnel               Conversion analytics
GET    /track/open/:logId    Email open tracking
GET    /track/click/:logId   Email click tracking
```

## Adding New Routes

### 1. Create a new file
```typescript

import { requireAdminAuth } from './middleware.js';

export function createNewDomainRoutes(container: Container): Router {
  const router = Router();

  router.get('/new-endpoint', requireAdminAuth, async (req, res) => {
    const db = container.resolve('db');
    // Implementation
    res.json({ success: true });
  });

  return router;
}
```

### 2. Update index.ts
```typescript
import { createNewDomainRoutes } from './new-domain.js';

export function createCrmRoutes(container: Container): Router {
  const router = Router();

  router.use('/', createContactRoutes(container));
  router.use('/', createCampaignRoutes(container));
  router.use('/', createLeadRoutes(container));
  router.use('/', createNewDomainRoutes(container));  // Add this

  return router;
}

export { createNewDomainRoutes } from './new-domain.js';
```

## Container Dependencies

Routes use the following container dependencies:

**Required**:
- `db` - Drizzle ORM database instance
- `emailScheduler` - Email processing service

**Usage**:
```typescript
const db = container.resolve('db');
const emailScheduler = container.resolve('emailScheduler');
```

## Database Tables

Routes access these tables:
- `users` - Contact information
- `emailQueue` - Pending emails to send
- `emailLogs` - Email delivery and engagement history

## HTML Templates

All HTML responses are generated by functions in `templates.ts`:

## Error Handling

Routes handle errors with try-catch blocks:

```typescript
router.get('/endpoint', requireAdminAuth, async (req, res) => {
  try {
    const data = await db.query.users.findMany();
    res.send(renderPage({ data }));
  } catch (error) {
    console.error('Error:', error);
    res.status(500).send('Failed to load page');
  }
});
```

## Performance Notes

### Client-Side Filtering
Contact lists are filtered in-memory. For large datasets (1000+ contacts), consider:
- Implementing server-side filtering with WHERE clauses
- Adding pagination
- Using database indexes on filterable columns

### Email Tracking
- Open tracking uses 1x1 pixel GIF (minimal overhead)
- Click tracking validates URLs against whitelist
- Both are fire-and-forget operations

### Template Rendering
- HTML rendering happens on-demand per request
- Consider caching for static templates
- CSS is embedded inline (ensures proper styling)

## Security Considerations

### HTML Escaping
All user input displayed in HTML must be escaped:
```typescript
import { escapeHtml } from './templates.js';

const safeName = escapeHtml(user.displayName);
```

### Redirect Validation
Click tracking validates redirect URLs:
```typescript
const ALLOWED_REDIRECT_HOSTS = ['anplexa.com', 'www.anplexa.com'];

if (requestedRedirect) {
  const url = new URL(requestedRedirect);
  if (ALLOWED_REDIRECT_HOSTS.includes(url.hostname)) {
    // Allow redirect
  }
}
```

### Authentication
All HTML routes require admin authentication:
```typescript
router.get('/protected', requireAdminAuth, handler);
```

## Troubleshooting

### emailScheduler not found
**Problem**: `container.resolve('emailScheduler')` returns undefined

**Solution**: Register in `container.ts`:
```typescript
emailScheduler: asClass(EmailScheduler).singleton(),
```

### Database connection errors
**Problem**: Routes fail to access database

**Solution**: Verify in `container.ts`:
```typescript
db: asFunction(({ pool }) => drizzle(pool, { schema })).singleton(),
```

### HTML rendering errors
**Problem**: Page loads with broken styling or layout

**Solution**: Check `templates.ts` `ANPLEXA_STYLES` constant and template functions
