## 💡 Content Quality Checklist (Use for Every Article)

### Before Writing
- [ ] Research keyword intent (informational vs commercial)
- [ ] Analyze top 10 ranking pages (identify gaps)
- [ ] Outline H2/H3 structure
- [ ] Plan internal links (8-12 per article)
- [ ] Identify external sources to cite (3-5)

### During Writing
- [ ] Primary keyword in H1, first paragraph, conclusion
- [ ] LSI keywords naturally distributed (2-3% density)
- [ ] Short paragraphs (2-4 sentences)
- [ ] Bullet points for scannability
- [ ] Include statistics with sources
- [ ] Add 3 Anplexa CTAs (early, mid, final)

### After Writing
- [ ] Proofread for grammar/spelling
- [ ] Check readability score (60+ Flesch)
- [ ] Verify all links work
- [ ] Add alt text to all images
- [ ] Implement schema markup
- [ ] Write meta title (<60 chars) and description (<160 chars)
- [ ] Optimize URL slug
- [ ] Run plagiarism check
- [ ] Mobile preview test
